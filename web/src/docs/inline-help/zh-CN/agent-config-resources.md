## Compute Resources

配置 workspace session 的计算资源限额。可选择预设规格或自定义各项数值。

### 注意事项

- Request 为保证分配量，Limit 为上限，需满足 Request ≤ Limit
- 集群资源不足时 session 会排队等待调度
- 存储在 session 之间持久化，不会因 session 结束而清除

## 并发与伸缩

「单副本并发」是一个副本同时接几个 turn，超出的排队等待。定时任务和交互式对话共用这一份额度。

自动伸缩的 workspace 还能调副本区间：

- 最少副本决定闲下来也保持运行的数量，最多副本是忙时的上限
- 扩容立即生效，缩容要连续几轮低负载才走，且只摘没有 turn 在跑的副本
- 「空闲后停止」到点会停掉整个 workspace，下次对话自动拉起——文件在共享卷上，不会丢
- 单副本还是自动伸缩在创建时定死，之后只能改数值
