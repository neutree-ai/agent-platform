One Linux machine, one command:

```bash
curl -sfL https://docs.neutree.ai/nap/get.sh | sudo sh -
```

It installs a single-node k3s cluster and the whole platform on it, then prints the URL and the admin credentials. Around five minutes. Overrides and the existing-cluster install are in the [single-node quickstart](/self-host/single-node/).
