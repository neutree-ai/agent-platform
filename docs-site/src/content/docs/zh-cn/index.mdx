一台 Linux 机器，一条命令：

```bash
curl -sfL https://docs.neutree.ai/nap/get.sh | sudo sh -
```

它会装好一个单节点 k3s 集群和整套平台，装完打印访问地址和管理员账号，大约 5 分钟。可覆盖的参数、以及装到已有集群上的方式，见[单节点快速部署](/zh-cn/self-host/single-node/)。
